# Payal Patil — Personal Portfolio

Welcome to my personal portfolio! This project showcases my technical skills, projects, education, and contact information as a fresher Java Full Stack Developer.

## 🚀 About the Project

The Payal Portfolio is a responsive personal website built using React. It highlights my development skills, academic background, and projects while providing an easy way for recruiters and developers to connect with me.

## 🛠️ Technologies Used

- **Frontend:** React.js, HTML5, CSS3, JavaScript
- **Build Tool:** Vite
- **Backend:** Spring Boot (planned for future integration)
- **Tools:** Visual Studio Code, Git, GitHub

## ✨ Features

- Professional introduction and profile
- About Me section
- Technical skills showcase
- Projects portfolio
- Contact information
- Responsive design for different screen sizes

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd payal-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173/`.
